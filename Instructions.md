Higharc Computational Geometry Engineer Challenge PART 1
========================================================

Open index.html in a browser to run the project. You can import JSON files in the vertex-edge format described in the instructions. The page will then process and present the output, displaying the faces using unique colors.
Some examples are included in the `examples` folder, and you can also create your own JSON files to test with different vertex and edge configurations. The output will show the faces identified in the graph, each colored differently for easy visualization.
If the input contains dangling edges, chains of dangling edges, duplicate edges, or zero-length edges they are first removed. The sanitized input is then used to find the faces. The html will show both the original and healed output.
